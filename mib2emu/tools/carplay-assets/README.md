`skoda-logo.png` is the official Škoda corporate logo, downloaded from
[Škoda Storyboard](https://www.skoda-storyboard.com/?attachment_id=349837).

Original asset:
https://cdn.skoda-storyboard.com/2023/12/Skoda_Corporate_Logo_RGB_Emerald_on_Electric_Green_efdf74e3.png

The receiver fits this image into a square PNG and supplies it as the native
CarPlay manufacturer icon, with the label “Škoda”. The logo remains Škoda's
trademark; it is separate from the emulator's source-code licence.
